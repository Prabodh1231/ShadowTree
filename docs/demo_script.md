# ShadowTree demo script (about 2.5 minutes)

Before recording: backend and `npm run dev` are running, the sample folder exists (`scripts\make_samples.py`), and the models have loaded once. Use a folder path that has no user name in it.

| # | Time | Click | Say |
|---|---|---|---|
| 1 | 0:00 | Open File Explorer on `sample_messy_folder`. Show the 8 files with messy names. | "This is a normal messy folder. `scan`, `Screenshot`, `voice memo`. I can't tell what is inside without opening each one." |
| 2 | 0:20 | Switch to ShadowTree. Point at the "Powered by Desert Ant Labs" footer only if asked. | "ShadowTree is a virtual file system. It sorts files with AI that runs on this PC. It never moves or changes my real files." |
| 3 | 0:30 | Paste the folder path. Press **Index (Read-Only)**. | "I give it the folder and press Index. It only reads." |
| 4 | 0:45 | Watch cards appear ("Reading your files…"). Click **All Files**, then a folder in the sidebar. | "Files show up while it reads. Each has a title, a summary and tags. The PDF, the screenshot and even the voice memo are understood." |
| 5 | 1:10 | Click **Sensitive (PII)**. Open the invoice card. In the drawer, toggle **Redacted**. | "Files with personal data land here. Emails and phone numbers are found on my machine and hidden in the Redacted view." |
| 6 | 1:35 | In **New Virtual Folder**, type a name such as "Money" and a short description. Note the emoji suggested. Press create. | "I can make my own folder. The app picks an emoji. It sorts my files into it by meaning, not by file name." |
| 7 | 1:55 | Click the search box. Type `money I spent`. | "I search in plain words. No file has these words in its name. The receipt and the invoice come first." |
| 8 | 2:10 | Open a result. Press **Reveal on Disk**. File Explorer opens on the real file. | "Reveal on Disk jumps to the real file." |
| 9 | 2:20 | Show the Explorer folder again. Same 8 files, same names, no new files. | "My folder is exactly as it was. No files moved, none added. Everything ran on this PC." |
| 10 | 2:30 | End on the grid. | "ShadowTree. Tidy view, same files, nothing leaves your computer." |

Tips: if the first search is slow, run it once before recording. Stop the backend with Ctrl+C when done.
